# 東林間HUB — まちの情報ステーション

東林間のお店・住民・イベントをつなぐ町おこしサイトの初稿です。会津若松の「マチイク」 https://aizu-machiiku.jp/ の案内所・地域活動・イベントという情報構成を参考に、文章、デザイン、イラスト、ソースを独自制作しました。参考サイトの画像や文章を転載していません。

## 使い方

index.htmlをブラウザーで開くだけで使えます。ビルド、npm、WordPress、データベースは不要です。ファイル一式を同じフォルダーに保ってください。

## GitHubで共有・公開する

1. GitHubで新しいリポジトリ `higashirinkan-hub` を作成します（公開サイトにする場合はPublic）。
2. 「Add file → Upload files」で、このフォルダーの**中身**をアップロードします。リポジトリの最上部に index.html、style.css、data.js、app.js、assets/town.svg を配置してください。
3. 「Commit changes」で保存します。リポジトリのURLでソースを共有できます。
4. サイトを表示するには、リポジトリの「Settings → Pages」で「Deploy from a branch」を選び、`main` と `/ (root)` を指定して「Save」を押します。
5. 公開完了後に表示されるURLを共有します。想定例：`https://tanzanbooks.github.io/higashirinkan-hub/`（リポジトリ作成・Pages設定前は未公開です）。

## 編集する場所

- `data.js`：お店・イベントのデータ。categoryはbooks / food / community。urlがnullの場合は外部リンクを表示しません。
- `index.html`：紹介文、町の記憶、相談先、サイト名。
- `style.css`：配色・レイアウト・スマホ対応。
- `assets/higashirinkan-1994.png`：提供された1994年の東林間商店街の写真を参考にしたイラスト。現在の街並みの再現ではありません。
- `app.js`：検索・カテゴリ絞り込み・詳細ダイアログ・モバイルメニュー・メール下書き。

## AIと地域情報の6つの入口

個人商店の広報支援（店主のおすすめ・開業の理由）、興味別まち歩き、昔の東林間と今をつなぐ展示・ZINE、ローカルニュース、近隣求人、イベント情報をサイトに追加しました。まち歩きはテーマを選ぶと3つの編集済みコース案から表示します。距離・所要時間・撮影地点は未確認です。各情報提供リンクから相談フォームの種類を選べます。

AIによるニュース・求人の定期更新コードを追加しました。有効化にはAUTO_UPDATE_SETUP.mdの設定が必要です。初回更新前は自動更新待ちと表示し、架空の記事や募集は掲載していません。運用時は原典・確認日・掲載許諾を記録し、主催者・店主・求人提供者に内容を確認してください。
